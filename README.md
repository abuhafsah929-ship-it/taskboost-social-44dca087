# TaskBoost Social

Create a modern responsive Social Media Task platform called "TaskBoost". The website should have a homepage, user registration and login, a user dashboard, a task page where users can complete social media tasks (Facebook likes, Instagram follows, TikTok follows, YouTube subscriptions, X follows), an earnings page showing completed tasks and balance, a referral page with a referral link and referral bonuses, a withdrawal request page, and an admin dashboard to create tasks, approve submissions, manage users, and approve withdrawals. Use a clean blue and white design with mobile-first responsive layout, notifications, profile settings, and secure authentication.
